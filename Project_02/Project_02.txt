# 🧠 Project 02 — Python Quiz Application

An interactive multiple-choice quiz application built with Python. The program presents five questions, evaluates user answers, tracks the score, and displays the final performance.

---

## 📌 Problem Statement

Develop a Python program that allows users to participate in a multiple-choice quiz consisting of five questions.

Each question should have four options (A, B, C, and D). The program must check the selected answer, provide feedback, and calculate the user's final score and percentage after completing the quiz.

## 🎯 Requirements

- [ ] Display a welcome message.
- [ ] Present five multiple-choice questions.
- [ ] Provide four options for each question.
- [ ] Accept answers from the user.
- [ ] Check whether each answer is correct.
- [ ] Award 1 point for every correct answer.
- [ ] Display feedback for correct and incorrect answers.
- [ ] Reveal the correct answer when the user answers incorrectly.
- [ ] Calculate the final score out of 5.
- [ ] Calculate the final percentage.
- [ ] Display a performance message based on the final score.

## 💻 Expected Output

