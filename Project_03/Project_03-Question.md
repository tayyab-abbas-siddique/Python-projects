# Project 03 – Student Information System

## Description

A simple Python program that collects and displays student information, including name, age, class, school, favourite subject, and enrollment status.

## Features

- Collect student information.
- Store information using variables.
- Display a formatted student profile.
- Accept different data types.
- Use f-strings for output formatting.

## Concepts Practiced

- Variables
- Strings and integers
- User input and output
- Type conversion
- f-strings

## Purpose

This project was developed to practice Python fundamentals and improve my understanding of variables, data types, and user interaction.

**Language:** Python
