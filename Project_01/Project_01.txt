🎮 Project 01 — Number Guessing Game

A simple interactive number guessing game built with Python. The computer generates a random number, and the player must guess it within a limited number of attempts.

📌 Problem Statement

Write a Python program that generates a random integer between 1 and 100. The user must guess the randomly generated number within 7 attempts.

After each guess, the program should provide a hint indicating whether the guess is too high or too low. If the user guesses correctly, display a winning message. Otherwise, reveal the correct number after all attempts are exhausted.

🎯 Requirements

Generate a random number between 1 and 100.

Allow a maximum of 7 attempts.

Accept guesses from the user.

Display Too High when the guess is greater than the secret number.

Display Too Low! when the guess is smaller than the secret number.

Display a congratulatory message when the user wins.

Count and display the attempts used.

Reveal the secret number if the user loses.

💻 Expected Output
